بدانید چرا.

Chera is a network diagnosis CLI for developers on filtered networks. It tells DNS poisoning, IP blocking, SNI filtering, block pages, provider geo-blocks, throttling and real outages apart, with evidence, a confidence level and a practical next step.

چرا یک ابزار خط فرمان برای عیب‌یابی شبکه است، مخصوص برنامه‌نویس‌هایی که پشت شبکه‌های فیلترشده کار می‌کنند. مسموم‌سازی DNS، مسدودسازی IP، فیلترینگ SNI، صفحه مسدودسازی، تحریم از سوی سرویس‌دهنده، محدودسازی سرعت و قطعی واقعی را از هم تفکیک می‌کند و شواهد، سطح اطمینان و قدم بعدی را نشان می‌دهد.

Every cause needs a different fix

هر علت، راه‌حل متفاوتی دارد

ping and curl only say "failed". Changing DNS does nothing against SNI filtering, and no network setting fixes a provider that refuses your country. Chera finds out which one you are dealing with.

ping و curl فقط می‌گویند «ناموفق». تغییر DNS در برابر فیلترینگ SNI بی‌اثر است و هیچ تنظیم شبکه‌ای مشکل سرویس‌دهنده‌ای را که کشور شما را رد می‌کند حل نمی‌کند. چرا مشخص می‌کند با کدام روبه‌رو هستید.

یک نتیجه برای هر سرویس

How it works

نحوه کار

Each layer runs separately and records exactly how it fails. A rule engine then picks the single most likely cause. Read the full guide.

هر لایه جداگانه اجرا می‌شود و دقیقاً ثبت می‌کند چطور شکست می‌خورد. سپس موتور قواعد محتمل‌ترین علت را انتخاب می‌کند. راهنمای کامل (انگلیسی)

  1. Local networkشبکه محلیInterfaces, default route, well-known hosts; proxy variables, OS proxy and VPN interfaces are noted so results are not misread.رابط‌ها، مسیر پیش‌فرض، میزبان‌های شناخته‌شده؛ پراکسی و VPN هم ثبت می‌شوند تا نتایج اشتباه خوانده نشوند.
  2. DNSSystem resolver vs. plain UDP vs. DNS-over-HTTPS. Block-page IPs such as 10.10.34.34–36, private answers and mismatches are flagged; a query to a non-DNS address reveals interception.DNS سیستم در برابر UDP ساده و DNS-over-HTTPS. آدرس‌های صفحه مسدودسازی مثل 10.10.34.34 تا 36، پاسخ‌های خصوصی و ناهمخوانی‌ها علامت می‌خورند؛ پرس‌وجو به آدرسی بدون DNS، رهگیری را آشکار می‌کند.
  3. TCPConnects to the correct (DoH) addresses and tells a silent timeout from an active reset.اتصال به آدرس‌های درست (از DoH) و تفکیک «پایان مهلت» از «ریست».
  4. TLS / SNIHandshakes with the real name; if that dies, retries the same IP with a neutral SNI and with none. Certificates are validated to spot interception.دست‌دهی با نام واقعی؛ اگر قطع شود، همان IP با SNI خنثی و بدون SNI امتحان می‌شود. گواهی برای تشخیص رهگیری بررسی می‌شود.
  5. HTTPClassifies the answer from the verified address: block page, provider geo-block, server error, or normal.دسته‌بندی پاسخ از آدرس تأییدشده: صفحه مسدودسازی، تحریم سرویس‌دهنده، خطای سرور یا عادی.
  6. Throttling (optional)محدودسازی سرعت (اختیاری)With --speed, compares handshake time and throughput with a baseline host.با --speed، زمان دست‌دهی و سرعت با میزبان مبنا مقایسه می‌شود.
  7. Outage checkبررسی قطعیWhen the path is clean but the service fails, asks its official status page.وقتی مسیر سالم است اما سرویس خطا می‌دهد، صفحه وضعیت رسمی آن بررسی می‌شود.

Verdicts

نتیجه‌ها

Every target gets exactly one primary verdict with a confidence of high, medium or low. Secondary findings are listed as also.

هر مقصد دقیقاً یک نتیجه اصلی با اطمینان زیاد، متوسط یا کم می‌گیرد. یافته‌های فرعی با «همچنین» نمایش داده می‌شوند.

VerdictنتیجهMeaningمعنی
OKThe real service answered over a verified path.سرویس اصلی از مسیر تأییدشده پاسخ داد.
LOCAL_NETWORK_DOWNNo interface, no route, or nothing reachable at all.رابط یا مسیری نیست یا هیچ چیز در دسترس نیست.
DNS_POISONEDYour resolver lies while DNS-over-HTTPS answers correctly.DNS شما پاسخ نادرست می‌دهد در حالی که DoH درست پاسخ می‌دهد.
DNS_INTERCEPTEDDNS is hijacked on the path; changing the resolver IP won't help.DNS در مسیر ربوده می‌شود؛ تغییر آدرس سرور DNS کمکی نمی‌کند.
IP_BLOCKEDPackets to the correct addresses are silently dropped.بسته‌ها به آدرس‌های درست بی‌صدا دور ریخته می‌شوند.
CONNECTION_RESETConnections are actively refused or reset.اتصال‌ها فعالانه رد یا ریست می‌شوند.
SNI_FILTEREDTLS dies after the ClientHello for this name only.TLS فقط برای این نام پس از ClientHello قطع می‌شود.
TLS_INTERCEPTEDUntrusted certificate or a TLS inspection product.گواهی نامعتبر یا محصول بازرسی TLS.
BLOCK_PAGEA government or ISP block page was served.صفحه مسدودسازی دولتی یا ISP نمایش داده شد.
PROVIDER_GEO_BLOCKThe real service refuses your region. Not a network problem.خود سرویس اصلی منطقه شما را رد می‌کند؛ مشکل شبکه نیست.
THROTTLEDWorks, but severely slower than a baseline host.کار می‌کند اما به‌شدت کندتر از میزبان مبناست.
UPSTREAM_OUTAGEClean path, but the service errors or reports an incident.مسیر سالم است اما سرویس خطا می‌دهد یا حادثه گزارش کرده است.
INCONCLUSIVENo clear cause; see --verbose.علت روشنی پیدا نشد؛ --verbose را ببینید.

Install

نصب

Download a binary from the latest release and verify it against checksums.txt, or install with Go.

فایل اجرایی را از آخرین release دانلود و با checksums.txt بررسی کنید، یا با Go نصب کنید.

With Go

با Go

go install github.com/assaabriiii/chera/cmd/chera@latest

Usage

استفاده

chera                     # default developer preset
chera github.com          # one host
chera --preset ai         # AI APIs
chera --verbose pypi.org  # raw evidence
chera --markdown          # report for an issue
chera --lang fa           # Persian output

From a release

از release

curl -LO https://github.com/assaabriiii/chera/releases/download/vX.Y.Z/chera_X.Y.Z_linux_amd64.tar.gz
curl -LO https://github.com/assaabriiii/chera/releases/download/vX.Y.Z/checksums.txt
sha256sum --ignore-missing -c checksums.txt
tar xzf chera_X.Y.Z_linux_amd64.tar.gz
sudo mv chera /usr/local/bin/

Presets: github, python, node, docker, huggingface, ai, go, rust, dev, all. Extend them with your own YAML.

پیش‌تنظیم‌ها: github، python، node، docker، huggingface، ai، go، rust، dev، all. با فایل YAML خودتان گسترششان دهید.
